# PAVEL MARKOV — PERSONAL EXPERIENCE

Персональный сайт Павла Маркова. React + TypeScript + Vite, статическая публикация GitHub Pages, без backend, регистрации и аналитики. RU/EN, две темы, подбор маршрута по прозрачным правилам, калькулятор времени, контакты Telegram/WhatsApp.

## Разработка

Требуется Node.js 24.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium firefox webkit
npm run test:e2e
npm run preview
```

Адрес разработки: http://127.0.0.1:5173/tapme/. Production preview: http://127.0.0.1:4173/tapme/.

## Данные и изображения

`src/config/profile.ts` — имя, рост, изменяемый вес, квалификации, проекты, ссылки и фото. `src/logic.ts` — правила маршрутов и проверяемая формула расчёта. Тексты интерфейса RU/EN находятся в `src/main.tsx`, `src/Services.tsx` и конфигурации. `src/style.css` — токены и адаптивная дизайн-система. Пустые ссылки соцсетей скрыты автоматически. Поля `cases`, `casteUrl`, `phone`, `document` зарезервированы; неподтверждённый контент не показывается как реальный.

Для документов квалификаций добавьте подлинные файлы в `public/media/` и URL в `document`; фиктивных подтверждений нет. Точный статус EREPS и программа ICA требуют уточнения владельцем. Спортивные звания представлены отдельно.

Медиа и кадрирование: [docs/media.md](docs/media.md). Manrope поставляется локально через @fontsource, лицензия SIL OFL в пакете. Все фото предоставлены владельцем сайта. Проектные композиции являются графическим оформлением, а не скриншотами интерфейсов.

## Приватность

В localStorage сохраняются только язык, тема и ответы маршрута. Никаких отправок на сервер. Кнопка в footer сбрасывает предпочтения. При недоступном хранилище сайт продолжает работать в памяти. Буфер обмена сообщает об успехе/ошибке. Telegram открывает профиль; WhatsApp получает текст обращения через параметр text. Обращение отправляет сам посетитель.

## Публикация

Workflow `.github/workflows/pages.yml` проверяет unit-тесты, сборку и Chromium/Firefox/WebKit, затем публикует `dist` через Pages. В Settings → Pages выберите GitHub Actions. Публикация: https://castefeudal.github.io/tapme/.

`dist/release.json` содержит SHA опубликованного коммита. Сопоставьте его с GitHub HEAD перед подтверждением релиза. Base path `/tapme/`, canonical, sitemap и social metadata требуют изменения при переезде на домен.

## Проверки и ограничения

Unit-тесты проверяют границы формулы и все 216 комбинаций ответов на двух языках. Playwright: маршруты, калькулятор, контакты, сохранение предпочтений, меню, отсутствие медиа, контроль ширин и Axe. Это автоматические проверки, не формальная сертификация WCAG, не проверка реальных iPhone/Telegram WebView и не полевые Core Web Vitals. Доставка сообщения в мессенджере требует ручной проверки владельцем; тесты сообщения не отправляют.
