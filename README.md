# PAVEL MARKOV — SIGNATURE EDITION

Личный сайт Павла Маркова: шесть глав, настоящие фотографии и продукты, единый инструмент YOUR NEXT MOVE. React + TypeScript + Vite, RU/EN, две темы, статический GitHub Pages. Без регистрации, backend, аналитики и платных API.

## Запуск и проверки

Node.js 24.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium firefox webkit
npm run test:e2e
npm run preview
```

Разработка: http://127.0.0.1:5173/tapme/. Production preview: http://127.0.0.1:4173/tapme/.

Для воспроизведения лабораторных измерений запустите production preview и затем `node scripts/lighthouse.mjs`. Скрипт выполняет три мобильных и три desktop-замера Lighthouse с чистыми профилями Chrome и сохраняет настройки и результаты в docs/performance. Не запускайте параллельно ресурсоёмкие тесты.

Подробный отчёт Signature Edition: [docs/signature-review.md](docs/signature-review.md).

## Архитектура

- `src/main.tsx` — сборка приложения; без содержимого отдельных глав.
- `src/components/` — Navigation, Hero, NextMove, ActionCard, Proof, Showcases, WorkWithMe, Connection, визуальные примитивы.
- `src/hooks/useExperience.tsx` — язык, тема, локальные предпочтения, буфер обмена и уведомления.
- `src/config/profile.ts` — персональные данные, вес, фото, квалификации, ссылки и соцсети.
- `src/config/routes.ts` — редактируемые цели и ограничения четырёх направлений.
- `src/config/showcases.ts` — тексты продуктовых мини-кейсов и настоящие снимки интерфейсов.
- `src/lib/plan.ts` — валидация и прозрачные правила персонального плана, календарные даты и расчёты времени.
- `src/lib/exports.ts` — PNG и RFC 5545 .ics, загружается только при экспорте.
- `src/styles/` — отдельные токены, типографика, motion и стили глав; нет общего монолитного CSS.

Сведения EREPS и ICA не дополняются выдуманными аккредитациями. Подлинные документы можно подключить через `qualifications[].document`. Спортивные звания отделены от образования. Пустые социальные URL показывают статус в футере; на первом экране доступны только заполненные ссылки. Телефон для vCard задаётся отдельно в profile.phone. MARKOVMADE, MARKOVGYM и PMWORK не изменяются.

## YOUR NEXT MOVE

Задача → ограничение → ресурс → действие. Для каждого направления четыре содержательные цели и четыре ограничения. Первый шаг, практика недели, измеримый показатель и объяснение правил учитывают ответы. Короткий ресурс даёт минимальную версию действия. Персональное название задачи не заменяет выбранную логику. Неизвестный ответственный явно отмечается как несогласованный.

Калькулятор сохраняет формулу `минуты × дни × недели × выполнение / 60`. В результате отдельно показаны недельные часы, суммарные часы, идеальный ресурс, разница и число запланированных занятий. Выполнение не трактуется как вероятность или гарантированный результат.

PNG создаётся на устройстве. .ics содержит выбранные занятия первой недели с еженедельным повторением на 4/8/12 недель и отдельную проверку в конце первой недели. Время — floating local time календаря, без скрытой конвертации в UTC. Пользователь может уточнить дату и время перед экспортом.

## Локальные данные

`pm-lang`, `pm-theme` и версионированный `pm-next-v2` хранятся только в этом браузере. Старый `pm-route` поддерживается при первом открытии. Некорректные сохранённые данные отбрасываются. Очистка доступна в footer. При отказе localStorage сайт работает в памяти; при отказе буфера обмена даётся понятное сообщение и доступный текст обращения.

Telegram открывает профиль; для передачи обращения есть копирование. WhatsApp включает текст через параметр text. Сообщение отправляет сам посетитель. Никакие данные не передаются автоматически.

## Медиа и визуальная проверка

[Медиа и происхождение снимков](docs/media.md). Основа: реальные фото владельца. Проектные скриншоты сняты с действующих публичных приложений; демонстрационные данные PMWORK подписаны как встроенный пример. Шрифты Manrope и Oswald хранятся локально, лицензии SIL OFL — в docs.

Исходный вариант: `docs/before/`. Матрица после переработки: `docs/evidence/` (1440/768/390/320, RU/EN, light/dark, ресурс, персональная карточка, контакт). Playwright создаёт реальные снимки; автоматической замены визуальных эталонов нет. В CI снимки сохраняются как browser-evidence, локально файлы доступны в рабочей папке.

Проверки переполнения используют `document.documentElement.clientWidth`, не `screen.width`. Для WebKit на Windows с системным DPI помощник сначала калибрует размер до запрошенной фактической CSS-ширины. Сравнение scrollWidth выполняется с этой измеренной шириной; допускается 1 px округления. После изменения viewport ожидаются шрифты и два кадра layout.

## Публикация и пределы доказательств

Workflow проверяет unit-тесты, production build и Chromium/Firefox/WebKit, затем публикует dist. Ubuntu-зеркала используют HTTPS. `release.json` содержит точный SHA релиза; публичный SHA проверяется отдельно от CI.

Lighthouse — лабораторная оценка. TBT не равен INP. Полевых данных Core Web Vitals пока нет; реальные iPhone, Telegram WebView и экранные дикторы требуют отдельной ручной проверки. Axe и клавиатурные тесты не являются формальной сертификацией WCAG или пользовательским исследованием.
