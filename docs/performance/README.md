# Лабораторная производительность

Последняя production-сборка, Lighthouse 13.5.0, Chrome из Playwright, Windows. Три независимых чистых профиля для каждого режима; симулируемое ограничение сети/CPU. Полные настройки — lab-settings.json; SHA256 проверенной сборки — audited-build.json. Итоговые значения — summary.json.

| desktop | 100 / 100 / 100         | 100 / 100 / 100                      | 554.106–570.469   | 0.000–0.000 | 0.000–0.000   |

Это лабораторные значения, не полевые Core Web Vitals и не гарантия на любом устройстве. INP полевыми данными не подтверждён. Максимальный desktop CLS точнее округления таблицы: 0.0002434950754078178.

Повторение: npm run build, затем npm run preview в отдельном терминале и node scripts/lighthouse.mjs. Для отдельного порта задайте LIGHTHOUSE_URL. Не запускайте одновременно другие браузерные тесты. Полные исходные JSON формируются локально; они исключены из Git из-за объёма.
