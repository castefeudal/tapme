# Медиа и происхождение

Все портреты предоставлены владельцем. Новые лица не генерировались. Шрифты Manrope и Oswald локальные, SIL OFL, лицензии в docs.

| Файл                                         | Назначение                        | Кадрирование                                              |
| -------------------------------------------- | --------------------------------- | --------------------------------------------------------- |
| hero-portrait.webp, hero-portrait-small.webp | MIND / обложка                    | 1200/600 px; центр, белый костюм, без арки                |
| fitness.webp                                 | BODY / личная спортивная практика | 600 px; лицо и награда, вертикальный исходник             |
| portrait-editorial.webp                      | SYSTEM / выступление              | 1280 px; лицо в верхней части кадра, Blockchain Life 2022 |
| caste.webp                                   | Образовательный проект            | 240 px, изображение целиком                               |

Главный портрет предзагружен с responsive srcset. Другие фото и продуктовые снимки lazy; контейнеры резервируют размеры. При ошибке изображения доступна типографическая композиция с alt-описанием, а содержимое и действия остаются рабочими.

## Реальные проектные снимки

Сняты 23 октября 2026 (Europe/Minsk), Chromium, исходная область 1440×1000, уменьшены до 1200 px WebP quality 85. Никакие элементы интерфейса не дорисованы.

- `markovmade-preview.webp`: https://castefeudal.github.io/markovmade/#calculators — открыт калькулятор питания и выполнен настоящий расчёт. Введены демонстрационные параметры: мужчина, 29 лет, 188 см, 100 кг; это пример, не актуальные данные Павла и не персональная рекомендация посетителю.
- `markovgym-preview.webp`: https://castefeudal.github.io/markovgym/#library — настоящая библиотека упражнений, без изменений продукта.
- `pmwork-preview.webp`: https://castefeudal.github.io/pmwork/ru/ — вкладка «Работа» встроенного демонстрационного проекта. Показатели и задачи принадлежат этому примеру; это не клиентский кейс и не заявление о реальных результатах.

Снимки подписаны и открываются в полном размере. Внешние приложения и их данные не менялись: взаимодействия происходили в изолированном тестовом браузере.

Исходные фотографии не нужны для production build. Для повторной оптимизации оригиналов: `node optimize-media.mjs "папка с исходниками"`.

## Проверка до и после

`docs/before/` содержит снимки версии до переработки. `docs/evidence/` — свежая матрица после. Эти файлы являются доказательствами осмотра, а не автоматически утверждёнными visual regression baselines. В CI они доступны в browser-evidence.
