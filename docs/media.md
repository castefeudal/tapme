# Медиа

Все файлы в public/media; адреса основных фотографий — src/config/profile.ts.

| Файл                    | Назначение                     | Рекомендация                                                      |
| ----------------------- | ------------------------------ | ----------------------------------------------------------------- |
| hero-portrait.webp      | Главный портрет                | От 1200 px по ширине, лицо по центру; белый костюм на чёрном фоне |
| fitness.webp            | Личная спортивная практика     | Вертикальный 600×770, кадрирование 50% 29%                        |
| portrait-editorial.webp | Выступление на сцене           | 1280×853, главный объект около 63% ширины                         |
| markovmade.webp         | Предоставленный фирменный знак | Квадрат 500 px; показывается целиком                              |
| caste.webp              | Знак образовательного проекта  | Квадрат 240 px                                                    |

Качество WebP 83. Главный портрет загружается приоритетно, остальные изображения lazy. Width/height и размеры контейнеров резервируют место. При недоступности медиа текст и действия доступны; никаких чужих лиц или вымышленных скриншотов. Указанные изображения не являются подтверждениями квалификаций.

Для реальных product preview можно добавить markovmade-preview.webp, markovgym-preview.webp и pmwork-preview.webp (рекомендуется 1440×900) и подключить вместо типографических композиций. Не выдавайте оформление за реальный UI.

Оптимизация исходников: `node optimize-media.mjs "папка с исходниками"`. Исходники с оригинальными именами остаются вне Git. Полученные WebP включены в репозиторий; сборка не зависит от локальных оригиналов.
